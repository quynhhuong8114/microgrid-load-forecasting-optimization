# Data setup

This project uses the **Building Data Genome Project 2 (BDG2)**, specifically hourly electricity measurements from seven selected educational buildings at the **Robin** site (2016–2017) and associated weather measurements.

**Original data source:** https://github.com/buds-lab/building-data-genome-project-2

## Files required to run Notebook 01

Download the relevant files from the official BDG2 repository and place them at these exact paths, relative to the main project directory:

| File | Used for | Expected layout |
| --- | --- | --- |
| `data/electricity_cleaned.csv` | Hourly electricity consumption | `timestamp` column plus building-ID columns |
| `data/metadata.csv` | Select educational buildings at the Robin site | Includes `building_id`, `site_id`, and `primaryspaceusage` columns |
| `data/weather.csv` | Weather features at the Robin site | Includes `timestamp`, `site_id`, `airTemperature`, `dewTemperature`, `seaLvlPressure`, and `windSpeed` |

In the [upstream BDG2 repository](https://github.com/buds-lab/building-data-genome-project-2), consult the `data/meters/cleaned/`, `data/metadata/`, and `data/weather/` directories. Preserve the filenames and column layout expected by the notebook; rename files locally as needed after downloading.

**No raw datasets are required to view the notebooks on GitHub.** They are required only to rerun preprocessing from scratch. Files such as `household_power_consumption.txt` and duplicate `.zip` archives are not read by the six uploaded notebooks.

## Generated by Notebook 01

The preprocessing notebook creates the following files:

| File | Purpose |
| --- | --- |
| `data/hourly_data.csv` | Aggregated hourly campus load joined with weather data |
| `data/featured_data.csv` | Engineered time-series features |
| `data/processed_data.npz` | Train, validation, and test arrays (`X_*`, `y_*`) |
| `data/scaler.pkl` | Fitted `MinMaxScaler` |
| `data/config.json` | Window length, selected buildings, features, and dataset settings (overwrites the version included with this repository) |

Notebook 01 constructs a campus demand profile from seven Robin educational buildings, creates 37 features, splits the series chronologically, fits the scaler on the training partition, and builds samples with a 48-hour input window and a one-hour forecasting horizon.

Notebooks 02–05 load the processed data and scaler, while Notebooks 05–06 rely on prediction archives written under `results/` by the model-training notebooks.

## Why the data files are not committed

The raw datasets are large, publicly sourced, and can be downloaded separately. The `.gitignore` file excludes them, along with generated preprocessing arrays. This keeps the GitHub repository lightweight while making the required inputs explicit.

If distributing any datasets or derived data separately, check the permissions and attribution requirements of the original source.
